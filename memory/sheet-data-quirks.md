Quirks in the published Google Sheet (URLs/gids in `src/constants.js`), found 2026-06-29:

- **"Monthly_5Y" tab (gid 755116259) is actually WEEKLY data** (~260 pts/5y, dates step 7 days), NOT monthly. Analytics `TIMEFRAMES['5y']` is configured cadence `weekly`, points 260, periodsPerYear 52 to match. If it's ever switched to true monthly, revert to 60 / 12.
- The weekly tab's Date column was ~92% empty earlier; after a script re-run it is now **100% dated** (both daily and weekly).
- **Analytics is now DATE-ANCHORED** (since 2026-06-30): `processHistory` returns `{dates, prices}` parallel arrays; `PerformanceLogic` builds a shared date axis (union of holdings' dates within the window), forward-fills via `priceAsOf`, anchors each timeframe to a real start date (`windowStartMs`; YTD → 1 Jan), and applies a time-based TER drag. This replaced the old position-based alignment, fixing the ~0.9pp mixed-portfolio error (e.g. `0P…` funds lag exchange ETFs by ~1 day / fewer points) and giving real x-axis dates. The `points` field in `TIMEFRAMES` is now unused (kept for reference).
- **Yahoo denomination glitches**: some LSE tickers (e.g. SMEA.L) have a ×100 jump in Yahoo history (re-denomination). `stitchDiscontinuities` in `PerformanceLogic` rescales the earlier segment so it can't blow up the base-100 index (was showing +14,590%).
- **Portfolios tab (gid 1724094727)** column headers drift: the holding-name column has been "Cash GBP" and "Asset Name"; `TargetWeight` mixes "99" and "89.50%". Parser handles both via `col()` candidates + `%` strip. See [[sheet-driven-presets]].
- Known ticker typos in the Portfolios sheet (won't plot in Analytics): `0P000TH0M.F` (→`0P0000TH0M.F`), `0P000VA0P.F` (→`0P0000VA0P.F`), `GB00B83HGR24.L` (→`0P0000WGSZ.L`).
- Stocks tab (gid 0) has `Region ` (trailing space) and `Class` columns — now captured into `pricesData` as `region`/`assetClass` for the Portfolios detail tab. **As of 2026-09-14 `Class` uses exactly the Charges tab's `Asset Type` names**: `Equities / ETFs` (109), `Funds` (26), `Bond Funds` (23), `Equity Funds` (18), `Money Market Funds` (9).
- **`Sector` column (Stocks tab)** — was present but unread until 2026-08-19; now parsed into `pricesData.sector`. **~131 of 184 rows are "Mixed"** because they're funds/ETFs with no single sector, leaving only ~53 single-company holdings. Market Pulse's sector board excludes "Mixed"/"Unclassified" for that reason — don't "fix" it by including them. Region is better populated (11 regions), but several hold 1–2 assets, and South Korea's two entries are the *same* iShares fund in Acc and Dist share classes, so group means over small `n` are duplicates, not breadth.
- **Charges tab (gid 1211950497)** — private-bank transaction fees, WIDE format: `Bank | Asset Type | Currency | Charge Minimum | (Tier,Percent)×5`. Tiers like `<50000`/`>500000`; percents `1.50%`. `processCharges` in `api.js` parses it → `{bank:{tiers,classes:{type:{rates,minCHF}}}}`; `computeTransactionFee`/`PB_CHARGES`/`mapBankClass` live in `constants.js` (PB_CHARGES is the fallback). Banks (2026-09-14): Schroders, Barclays, JB, No Charge, EFG, LO, LGT Singapore (bank names have apostrophes stripped, e.g. `Schroder's ` → `Schroders`). Min tickets are in CHF; trade value is converted to CHF (live) to pick the tier. Used by the **Private Bank Rebalancer** (sub-tab under Rebalancer). `parseSheetPromise` now trims headers globally (`transformHeader`).
- **Fee-category mapping trap (fixed 2026-09-14):** because Stocks `Class` == Charges `Asset Type`, `mapBankClass` must try an exact (case-insensitive, trimmed) match first. The keyword fallback alone sent `Equity Funds` → `Equities / ETFs` (contains "equit") and `Funds` → whatever category containing "fund" comes first in the sheet's row order (`Equity Funds` on the live sheet, `Money Market Funds` in `PB_CHARGES`). That was wrong at all 7 banks, but only visible where the rates differ. Barclays: Equity Funds 1.25/1.00/0.75/0.50% vs ETFs 1.50/1.20/1.00/0.80%, and Funds 1.80/1.50/1.20/0.80%, so the fix raises Funds fees there. LO: Funds 0.50/0.43/0.33/0.28% vs Equity Funds 0.68/0.55/0.43/0.38%, so it lowers them. JB, No Charge, EFG and LGT Singapore charge the same for all three. Schroders' Equity Funds, Funds and ETFs rows are identical, which is why it hid the bug. Keep the keyword fallback: it handles `Cash`, the `'Equity'` blank-row default, and future renames. If the sheet's category names change, re-run the Python old-vs-new mapping check.
